# Screenshots

Place PNG screenshots here. Paths must match `app.json` → `media.screenshots`.

## Expected files

| File | Mockup screen to capture |
|------|--------------------------|
| `01-home.png` | Welcome screen |
| `02-feature.png` | Feature / core flow screen |
| `03-results.png` | Results or outcome screen |

## How to capture

1. From package root: `npm run dev`
2. Navigate to the target screen in the mockup
3. Capture at mobile width (~375px)
4. Save with the exact filenames above

## Landing page

The transform copies files to `landing-template/app-data/images/` and sets paths in `app-config.json`. Do not rename without updating `app.json`.
